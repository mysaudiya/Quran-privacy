Политика конфиденциальности Quran

Последнее обновление: 11 сентября 2026 г.

Приложение Quran уважает конфиденциальность пользователей. Приложение не требует регистрации и не собирает персональные данные пользователей.

Локальные данные

Приложение может локально хранить на устройстве пользователя: последнюю позицию чтения, закладки, прогресс чтения, данные плана хатма, выбранную тему, размер текста, настройки перевода, автопрокрутки, выбранного чтеца и другие настройки приложения.

Эти данные хранятся только на устройстве пользователя и не передаются разработчику или другим пользователям.

Персональные данные

Quran не запрашивает имя, адрес электронной почты, номер телефона, адрес проживания или другие персональные данные.

Аналитика и реклама

Приложение не использует рекламные SDK, Firebase Analytics, Crashlytics или другие системы аналитики и отслеживания пользователей.

Разрешения устройства

Приложение не использует геолокацию, контакты, камеру, микрофон, фотографии или видео пользователя.

Аудио Корана

Для воспроизведения аудио аятов приложение может обращаться к внешнему сервису everyayah.com. В запросах используются только данные, необходимые для выбора аудио, например номер суры, номер аята и выбранный чтец. Закладки, прогресс чтения и другие локальные настройки не передаются.

Передача данных третьим лицам

Приложение не продает и не передает персональные данные пользователей третьим лицам.

Изменения политики

Настоящая политика конфиденциальности может периодически обновляться. Актуальная версия будет опубликована по этому адресу.

Контакты

По вопросам конфиденциальности можно связаться с разработчиком: support@shagru.ru
